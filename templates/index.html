Why Max Heap?

A Max Heap keeps the highest-priority patient at the root, allowing O(1) access to the most urgent case.

OperationTime
Insert PatientO(log n)
Remove HighestO(log n)
View HighestO(1)
Build HeapO(n)

Pseudocode

START

Create empty Max Heap

FOR EACH arriving patient:
    Read patient details
    Assign priority
    Insert patient into Max Heap
    // O(log n) — heapify up

WHILE patients are waiting:
    patient ← ExtractMax(heap)
    // O(log n) — heapify down
    Send patient for consultation
    Update patient status

END
