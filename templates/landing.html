Algorithmic Core

Why Max Heap Priority Queue?

In healthcare triage, conventional FIFO (First-In, First-Out) queues can lead to catastrophic delays for critical patients. Max Heap guarantees immediate access to the highest urgency cases.

Insert (Heapify-Up)

New patient placed at array leaf and bubbled up by priority comparisons.

Time: O(log n)

Extract-Max (Heapify-Down)

Highest-priority root is called; last element moves to root and sinks into place.

Time: O(log n)

Peek Highest Priority

Root element index [0] is inspected without removing it from the queue.

Time: O(1)

Build Heap Construction

Bottom-up heapify algorithm converting an unsorted database state into a valid heap.

Time: O(n)
